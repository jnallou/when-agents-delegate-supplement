# Supplementary Materials — When Agents Delegate: Accountability Chains in Multi-Agent AI Systems

**Author:** Ornella Bahidika, Independent Researcher, Seattle, WA, USA

Supplementary materials accompanying the article published in the International Journal of Advanced Computer Science and Applications (IJACSA).

## Contents

- **S1 — `S1-audit-working-notes.md`**: Audit working notes for the protocol and framework audit reported in Section VI of the article. Per-assessment verbatim quotations, source URLs, and rationale for all twenty-five verdicts (five artifacts × five chain conditions). Artifacts audited: Model Context Protocol (specification revision 2026-07-28), Agent2Agent protocol (1.0.0), LangGraph, Microsoft AutoGen, and the OpenAI Agents SDK (documentation as of August 2026).
- **S2 — `S2-audit-evidence.json`**: Machine-readable audit evidence: the same twenty-five assessments as structured records (artifact, condition, verdict, quotations, source URLs, rationale, audit date).

## Citation

Bahidika, O., "When Agents Delegate: Accountability Chains in Multi-Agent AI Systems," International Journal of Advanced Computer Science and Applications (IJACSA), 2026.
